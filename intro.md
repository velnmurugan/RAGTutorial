# Grounded AI

Welcome. This is a hands-on, from-scratch course on Retrieval-Augmented
Generation (RAG) — no machine learning background required.

Every chapter mixes plain-language explanation with code you can run and
edit right in the page, plus a short self-check at the end. Nothing here
assumes you already know what an embedding is.
